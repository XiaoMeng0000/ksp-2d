# KSP 2D 图片注册/加载标准化流程 v1.0

## 一、总则（铁律）

1. **唯一注册中心**：所有图片必须在 `src/graphics/textureConfig.js` 声明 key→path，由 `textureManager` 统一加载
2. **禁止硬编码**：业务代码禁止 `new Image()`、禁止写死图片路径
3. **永远带 fallback**：纹理未就绪/加载失败时，必须回退到 Emoji 或程序化绘制
4. **分类存放**：素材必须放对应分类文件夹，不堆在 `images/` 根目录

## 二、素材放置规范

```
assets/images/
├── menu/            主菜单（背景、Logo、反馈图标）
├── ui/              通用 UI（时间加速、垃圾桶等）
├── sas/             SAS 模式图标
├── facilities/      设施
│   └── compartments/ 设施舱室
├── celestial/       天体贴图
├── ships/           飞船
│   └── bodies/      船体图标（飞行场景）
```

## 四、六大场景标准流程

### 场景 1：DOM 图标（面板/列表/工具栏）

**链路**：`textureConfig → textureManager → renderIconHtml() → <img>`

```
① 放图片  → assets/images/对应分类/
② 注册    → textureConfig.js 加一行  key: 'path'
③ 使用    → ${renderIconHtml('key', '❓', 尺寸)}
```

**已有实现**：`uiComponents.js`、`menuUI.js:12`、`flightUI.js`、`sasUI.js:718`、`timeWarpUI.js:338`、`main.js:433`

**SVG 图标规范（0.3.0 图标替换，沿用 escMenu/tracking 案例 + 新 sas 图标）**：

- SVG 必须带 `width` + `height` + `viewBox` 三件套（textureManager 用 `new Image()` 加载，缺尺寸部分浏览器 drawImage/布局异常）；
- **白色单色模板底稿**：图标形状用白色描线绘制，激活/未激活等状态色由渲染层运行时染色（Canvas 用离屏 `source-in` 模板染色，见 `sasUI.js _tintImage`；DOM 用 CSS `mask-image` + `background` 染色）；
- 优点：美术只出一张白稿，状态色（如顺逆黄/径向青/未激活深灰/SAS 绿）全部由代码按状态控制，与追踪站 `all.svg` 的 `currentColor` 思路一致。

### 场景 2：Canvas 全屏背景

**链路**：`textureConfig → textureManager → drawImage`

```
① 放图片  → assets/images/menu/
② 注册    → textureConfig.js 加 menu_bg
③ 使用    → 优先 drawImage(bg, 0,0,W,H)；失败 fillRect(black) + 原有星空绘制
```

**参考**：`menuScene.js:238`

### 场景 3：Canvas 场景静态图（Logo/海报）

**链路**：`textureConfig → textureManager → drawImage / img.src`

**参考**：`menuScene.js:90`、`splashScene.js:81`、`creditsScene.js:24/133`、`licenseScene.js:74`、`galaxiesScene.js:53`

### 场景 4：Canvas 天体贴图

**链路**：`textureConfig → textureManager → drawImage`

```
注册示例：kerbin_surface: 'assets/images/bodies/kerbin.png'
```

### 场景 5：Canvas 轨道图标（飞船/设施）

**链路**：`textureConfig → textureManager → drawImage（带解析优先级）`

**飞船解析优先级**（`renderer.js:297`）：

```
① s.iconTextureKey 有值 → textureManager.get(ship_xxx)
② 为空 → 受控 ship_default_active / 非受控 ship_default_inactive
③ 纹理未加载 → 程序化三角形
```

**缩放保护**：受控/选中 `max(14, 16*zoom)`，非受控/未选中 `max(4, 8*zoom)`

### 场景 6：renderableManager 实体（可选多层渲染）

**链路**：`textureConfig → textureManager → renderableManager → renderer.js layer.texture`

```
main.js TEXTURES_READY 回调中：
renderableManager.register('facility', { layers: [{ texture: 'facility', ... }] })
```

**参考**：`main.js:213`、`renderer.js:40/361`

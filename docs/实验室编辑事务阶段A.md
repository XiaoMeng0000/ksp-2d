## 唯一正式设计与操作草稿

`GameState` 的专用实验室会话入口持有 `design / held / edit / undo / redo`。
该会话不放入 `_state.ships`，不参与 `getState()` 的战役深拷贝/存档；进出实验室独立建立和清理。
场景中的 `_design` 是当前显示数据的引用，不是第二份独立持久化数据。

纯逻辑位于 `src/partlab/editorTransactions.js`：

| 操作 | 正式 design | 历史 |
|---|---|---|
| 从目录拿起 | 不变 | 不变 |
| 从主船拿起完整子树或现有对称组 | 不变；表现层暂时隐藏被拿起实例 | 不变 |
| 移动鼠标/吸附预览 | 不变；独立候选计算整枝位姿 | 不变 |
| 确认有效放置 | 一次替换，保留移动实例的 ID/资源/后代/内部连接 | 一条 |
| 取消或失败 | 不变 | 不变，保留 redo |
| 删除已有手持组件 | 一次移除该组件全部实例 | 一条 |
| 删除目录新件 | 仅取消手持 | 不变 |
| 连续属性滑块输入 | 只更新 `edit.draft`，面板/参数预览读取草稿 | 不变 |
| 滑块 change/focusout | 提交草稿 | 有变化才一条 |
| pointercancel / 失焦中断 | 取消操作、恢复正式设计 | 不变 |

撤销/重做遇到手持或草稿时，先取消当前操作，不跨越历史。相机、预览、hover 不进入历史。
保存/导出前完成属性编辑并取消未放置组件；只保存完整正式设计。

## 整枝与对称边界

- 移动保留完整实例快照，不再删除后仅记住 `typeId`。
- 手持组包含现有对称伙伴及各自后代，但仍是单个操作，不是多工作区装配体。
- 现有 `rotationY` 下，子件位置和朝向随根刚体变换。
- 已有组件移动保留对称数量；改变已有组数量和建立新后代对应关系留给 B。
- 放置只允许与手持根数量相同的目标集合；一个堆叠节点不能接受多个根。
- 提交复核基础条件：父件/节点存在、未占用、类型/方向/尺寸、有限位姿、不得挂到自身或后代。遮挡筛选与完整碰撞规则不在本批。

## 输入与 UI

- **左键点一下已放置部件 → 立刻拎起整枝**（按下即拿起，松手也不放下；移动鼠标继续跟着走）。
  这是 KSP 原版手感：拿起和放下是两次独立点击，没有「阈值」或「原地松手」之类的中间态。
- **再次左键单击有效挂点 → 安装**；右键单击或 `Esc` → 取消，原样恢复。
- **放置完成后不自动选中新件**：落件即结束本次操作，不需要再点一下空白处取消高亮；
  想调燃料/配重时右键该部件打开属性窗。
- 目录 `pointerdown` 拿起，支持点击拿起再单击放置，以及拖出松手放置。
- 相机：空白处左键/右键拖动旋转，中键或 `Shift+右键` 垂直平移；拖动相机不会误安装或取消。
- 工具栏、分类、属性控件不隐式丢弃手持组件；零件库空白操作是取消，删除按钮才删除已有组件。
- 视口显示整枝 3D 半透明虚影；鼠标移到面板上时改用跟随光标的缩略图徽标提示。
- 数据事件不再重建零件库 DOM；异步缩略图原位更新，避免 pointerdown 后事件目标消失。
- 普通滑块更新不重建 PAW；撤销/重做时明确刷新属性窗。

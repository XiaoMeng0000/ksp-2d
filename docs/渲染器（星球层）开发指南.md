## 2. 一帧的数据流

```
menuScene.render(ctx)
  ① 背景（星点 或 menu_bg 图片）
  ② menuPlanetLayer.render(ctx)
       ├─ renderer.setPlanet({...})   ← 参数来自 menuPlanetConfig + bodyRenderShape + biomeRelief
       ├─ renderer.setCamera({cx,cy}) ← 用"外接球半径"口径把球放到指定屏幕位置
       ├─ renderer.render(dt)         ← 透明模式：离屏 clearColor alpha=0 + 铺屏 alpha 透传
       └─ ctx.drawImage(glCanvas)     ← **每帧一次**，唯一的合成调用点
  ③ 飞船/设施/HUD（HUD 由场景层在 render() 之后画 ⇒ 天然在球之上）
```

`update(dt)` 负责时间推进（自转/云演化）；`exit()` 只 `releaseTargets()`，**不 dispose**（菜单可反复进入，单槽初始化 p95≈87.9ms，别每次重建）。

## 3. 不变量（改任何东西都要守住）

1. **五项契约形状不变**：`createPlanetRenderer / setPlanet / setCamera / render / resize`；新能力只做**加法**（新增方法 / 可选参数）。
2. **默认路径逐像素零回归**：`normalStrength = 0`、`cloudEnabled` 等默认关 ⇒ 与接入前逐像素一致（守了多批的硬杠）。
3. **`screenRadiusPx` = 外接球半径**：`physScreenR = screenRadiusPx × circumscribedRatio`（球体 = 1；不规则体 = `1 + Σ|amp|`）。
4. **逐群系 relief 必须显式传入**：`setNormalMap(img, { relief })`。
   ⚠️ **漏传 = 全 1 = 海面长山**（本项目踩过：接入卡漏写，菜单差点带病上线）。
5. **资产禁止重编码**：渲染器上传为 `RGBA8`（无 sRGB 解码）⇒ 重压缩会改观感；尺寸/档位在**烘焙端**决定。
6. **渲染层无业务逻辑**：不读 `GameState`/`eventBus`/`sceneManager`，不碰 DOM；输入只经参数。
7. **失效路径非静默**：缺资产（`RENDER_ASSETS_MISSING`）、上下文丢失、无槽/超容都要带 reason 上报。

## 4. 想改东西时的正确入口

| 想改什么 | 怎么做 |
|---|---|
| **菜单观感**（强度/位置/光照/云） | 改 `menuPlanetConfig.js` —— 不改代码 |
| 换天体 / 加天体 | 实验室烘 → `node tools/importRenderAssets.mjs --body <id>` → 配置 1 条（成本预算 G1） |
| **渲染逻辑 / 着色器** | **回实验室改** → 重新 vendor（§5）——**不要在游戏里直接改镜像** |
| 加渲染参数 | 加到渲染器的 `DEFAULT_RENDER_PARAMS`（**不要动** `renderParamKeys.js`，那是"额外键"表） |
| 加资产类型 | 加一个 **family**（不要改既有 family 结构），并同步 `importRenderAssets.mjs` 的校验分层 |

## 5. vendoring 规则（**最重要**）

- `src/planet|glCore|geometry` 是**镜像**，唯一允许的本地改动 = 首行 `"use strict";` → `'use strict';`。
- 改渲染逻辑的流程：**实验室改 → 提交 → 复制到本仓 → 更新 `src/planet/VENDORED.md`（来源 commit + 逐文件 sha16）**。
- 判定漂移：与实验室同名文件 diff **超过那一行引号** = 漂移，必须回实验室改或说明原因。
- 现状：`VENDORED.md` 记录了来源 commit 与本次 UBO 修复的增补记录。

## 6. 坑位清单（都是本项目实际踩过的）

1. **同一 WebGL 上下文里 `setPlanet` 之后再改参数，画面不更新** ⇒ 做零回归对比必须**一例一上下文**（否则会拿到陈旧帧，误判"一致"）。
2. **GL 包装层 UBO**：`createUniformBlock` 必须**创建即按声明尺寸分配并 `bindBufferBase`**；否则带 active uniform block 的着色器（如云）每次 draw 触发 `GL 1282`，**整帧被静默拒绝** —— 这是"菜单没云"的根因。
3. **资产缺失必须显式**：`jool` 无 albedo/normal ⇒ 走 `RENDER_ASSETS_MISSING`，**不进渲染**；`setAlbedo(null)` 会硬报错，不能拿 null 表示缺。
4. **群系强度度量**：用 `p95 坡度` 会被 fbm 高频噪声抬高（平原被估成山地的 79%）⇒ 已改**低频幅度法**；注意块平均会**低估窄山脊**（mountain 需手调）。
5. **极点**：法线图 U 向在纬度 >75° 后有 3.86× 放大 ⇒ 必须**着色器极点淡出**（`poleFade = 1 − smoothstep(0.75, 0.95, |v−0.5|×2)`），否则出现径向条纹。
6. **盘心竖缝是证据工具的取景伪影，不是渲染缺陷**：相机正对 u=0/1 时出现；把 `spinDeg` 转开（如 90°）即消失。曾误判为产品缺陷。
7. **文档与实现不一致会误导**：例如"方案写 Sobel、实现是中心差分"、"注释说缺省全 1"——改口径时同步改注释。

# KSP 2D 音频注册/加载/播放标准化流程 v1.0

## 一、总则（铁律）

1. **唯一注册中心**：所有音频必须在 `src/audio/audioConfig.js` 声明 key→path，由 `audioCore` 统一加载解码
2. **禁止硬编码**：业务代码禁止 `new Audio()`、禁止直接操作 AudioContext、禁止写死音频路径
3. **事件驱动决策**：播放/停止决策全部由 `audioDirector` 订阅事件总线完成；业务层只 emit 游戏事件，不直接调用播放
4. **数据驱动映射**：场景→音乐、天体分类→音乐 的映射只写在配置里，不写死在逻辑中
5. **分类存放**：音乐放 `assets/audio/bgm/`，音效放 `assets/audio/sfx/`，不堆根目录
6. **永远带容错**：音频未就绪 / 资源缺失时静默跳过，绝不阻塞游戏流程、不抛异常

## 二、素材放置规范

```
assets/audio/
├── bgm/   背景音乐（菜单、飞行、追踪站）
└── sfx/   UI 与游戏音效（预留空目录，待音效任务填充）
```

## 三、命名规范

**文件名**：`{场景}_{分类}.ogg`

| 文件 | 含义 |
|------|------|
| `menu1.ogg` / `menu2.ogg` | 菜单音乐变体 KSP1 / KSP2 |
| `flight_terrestrial.ogg` | 类地天体（Kerbin）飞行音乐 |
| `flight_mun.ogg` | Mun 分类飞行音乐 |
| `flight_star.ogg` | 恒星（Kerbol）飞行音乐 |
| `tracking.ogg` | 追踪站音乐 |

**资源标识**（manifest 键）：`music:<sceneKey>[_<variantKey|bodyType>]` 或 `sfx:<key>`

| 标识 | 示例 |
|------|------|
| `music:menu_ksp1` | 菜单 KSP1 变体 |
| `music:flight_mun` | Mun 分类飞行音乐 |
| `music:tracking` | 追踪站（无子项结构） |

**天体音乐分类**（`CelestialBody.musicType`）：`terrestrial` / `mun` / `star` / `icy` / `rocky` / `gas` / `eve` / `duna` / `deepSpace`

## 四、驱动链路总览

```
audioConfig（注册）──▶ audioCore（加载/解码/播放/音量总线）──▶ 出声
                           ▲ 事件
audioDirector（订阅事件总线，查表决策）
   └─ SCENE_CHANGED / SOI_CHANGED ─▶ gameState ─▶ getMusicTypeForSOI ─▶ audioCore.playMusic
```

三层职责：`audioConfig` 数据层（声明）、`audioCore` 引擎层（播放能力）、`audioDirector` 决策层（事件→动作）。业务层与音频完全解耦。

## 五、三大场景标准流程

### 场景 1：固定场景音乐（菜单 / 追踪站）

**链路**：`audioConfig → audioDirector(SCENE_CHANGED) → audioCore.playMusic(sceneKey[, variant])`

```
① 放音乐  → assets/audio/bgm/
② 注册    → audioConfig.js musicMap 加条目
             （variants 结构支持同一场景多曲切换）
③ 接线    → audioDirector._handleSceneChanged 加 to===sceneKey 分支
④ 生效    → 进入场景自动播放，离开自动停止
```

**参考**：`audioDirector.js:38`、`settingsScene.js`（菜单音乐 KSP1/KSP2 按钮组）

### 场景 2：飞行场景按宿主天体分类选曲

**链路**：`audioConfig.byBodyType → audioDirector(SCENE_CHANGED / SOI_CHANGED) → getMusicTypeForSOI → audioCore.playMusic('flight', musicType)`

```
① 放音乐  → assets/audio/bgm/flight_<分类>.ogg
② 注册    → audioConfig.js musicMap.flight.byBodyType 加一行  <分类>: 'path'
③ 标天体  → solarSystem.js 给 CelestialBody 加 musicType: '<分类>'（与 byBodyType key 一致）
④ 生效    → 进入飞行按焦点天体播，SOI 跨越自动切曲
```

**规则**：
- 焦点优先级：活动飞船 > 活动设施（设施模式下 `activeShipId` 为 null，回退查活动设施的宿主天体）
- 深空（无 SOI）→ `deepSpace`；天体未分类 → 兜底 `rocky`

**参考**：`physics.js getMusicTypeForSOI`、`audioDirector.js:57`

### 场景 3：音效（已实现）

**链路**：`audioConfig.sfxMap → UI 层 emit(UI_PANEL_OPENED/CLOSED) → audioDirector 查表播放 → audioCore.playSfx`

当前状态：`playSfx` 播放接口已实现（`audioCore.js`，走 `_sfxGain` 总线、播完自动清理节点），UI 面板开关音效已接入：
- 面板打开：`uiManager.showPanel` / 对话框创建等 emit `UI_PANEL_OPENED`，audioDirector 查 `panelOpenSfxMap` 播放（**ESC 菜单播放专属 `ui_esc_open`，其余统一 `ui_panel_open`**）
- 面板关闭：`uiManager.hidePanel` / 对话框关闭路径 emit `UI_PANEL_CLOSED`，统一播放 `ui_panel_close`（**120ms 延迟窗口**：①批量关闭合并为一声;②关闭后紧接打开(如 ESC→设置 互斥切换)时取消关闭音，只响打开音）
- 资产标识：`ui_panel_open` / `ui_panel_close` / `ui_esc_open`（素材路径 `assets/audio/sfx/`）

**UI 点击音效**：`uiClickSfx.js`（document 捕获阶段委托）识别 UI 元素点击 → emit `UI_CLICKED`（payload 含 `variant` 与 `yRatio`=按钮中心 y/视口高度）→ audioDirector 查 `uiClickVariantConfig` + 位置变调播放：
- 普通点击：volume 0.75（总监定稿 3/4 音量），rate = 位置变调
- **选中式按钮"已选中再点"**：`selected` 变体（volume 0.45 / rate 0.85 → 更闷、更小），覆盖 settings-btn.selected / .nc-mode-selected / .tracking-tab-active / .settings-cat.active / .sgp-selected 等
- **屏幕位置变调机制**（正式引入，悬停音复用）：rate 随按钮 y 位置线性映射——屏幕中间 1.0 原调、越上越高、越下越低，**幅度 ±25%（rate ∈ [0.75, 1.25]）**；最终 rate = 变体率 × 位置变调率
- **方案 A 面板音让位（细化）**：点击音 80ms 到期时检查关闭音是否仍在排队——关闭音将真实播放则点击音让位；关闭音被静默/取消（如场景切换吞掉、ESC 静默清单）则点击音照播。打开音让位保持"立即取消待播点击音"（点"开始游戏"只响打开音）
- 排除：`.timewarp-cell`（档位音见下）、場景切换链路（SCENE_CHANGED 时取消待播点击音）
- **点击音不受场景切换影响**（总监要求）：场景切换只静默面板开/关音，ESC→追踪站等切换链路的按钮点击仍响点击音
- 资产标识：`ui_click`（素材路径 `assets/audio/sfx/ui_click.ogg`）

**时间加速档位音效（激活 + 悬停）**：音调按**档位格序线性映射**（`getWarpSfxRate`，非屏幕位置）——**1x（最左格）= 文件原调（rate 1.0）**，向右每格升高 0.05，**最右格（10,000,000x）= +50%（1.5）**（总监定稿：初始 +25% 区分度不足，改为 +50%）：
- 激活：点击档位格与键盘快捷键**统一汇入 `TIME_WARP_CHANGED`** → audioDirector 播放 `sfx:warp`（volume 0.75）
- 悬停：`timeWarpUI` 档位格暴露 `data-rate`，`uiClickSfx` mouseover 前置分支 emit `UI_WARP_HOVERED` → 播放 **`sfx:warp_hover`（独立音频文件）**（volume 0.35，与 UI 悬停音一致）
- **0x 暂停专属**（总监约定）：进入暂停 → `warp_pause` 专属音；**取消暂停（恢复）→ `warp_resume` 专属音，覆盖恢复档位（含 1x）的激活音**；判定依据 = `TIME_WARP_CHANGED` payload 的 `paused` / `wasPaused`（timeWarp.js 已扩展）
- 资产标识：`warp` / `warp_pause` / `warp_resume`（素材路径 `assets/audio/sfx/`）

**UI 悬停音效**：`uiClickSfx.js` 的 document `mouseover` 捕获阶段委托（与点击共用 HIT/EXCLUDE 选择器，同元素内移动不重播）→ emit `UI_HOVERED`（payload `{ yRatio }`）→ audioDirector 立即播放：
- 音量 0.35（`uiHoverConfig`，总监定稿 = 初版 0.5 的 0.7 倍）；音调 = 位置变调（与点击音同机制，±25%）
- 排除：`.timewarp-cell`（档位音另一套）
- 资产标识：`ui_hover`（素材路径 `assets/audio/sfx/ui_hover.ogg`）

**规则**：UI 层 emit 事件，audioDirector 查 `sfxMap` 播放，业务层不直接出声（总监既定规则：UI 点击音效为另一套，后续以变调机制扩展，见音效任务规划）。

## 六、audioDirector 事件订阅表

| 事件 | 条件 | 动作 |
|------|------|------|
| `SCENE_CHANGED` | `to === 'menu'` | `playMusic('menu', getMenuMusicVariant())` |
| `SCENE_CHANGED` | `to === 'flight'` | 按焦点物体天体分类播放 |
| `SCENE_CHANGED` | `to === 'tracking'` | `playMusic('tracking')` |
| `SCENE_CHANGED` | `from ∈ {menu, flight, tracking}` 且到无音乐场景 | `stopMusic()` |
| `SOI_CHANGED` | 当前场景为 `flight` | 重新按焦点物体天体分类播放 |
| `SOI_CHANGED` | 当前控制飞船跨界 | 随机播放 `soi_change` 变体之一 |
| `UI_PANEL_OPENED` | payload `{ panelId }` | 查 `panelOpenSfxMap` 播放（esc 专属，其余统一）；播放前取消待播关闭音 |
| `UI_PANEL_CLOSED` | payload `{ panelId }` | 延迟 120ms 播放 `ui_panel_close`（批量合并 / 紧接打开则取消）；**场景切换静默窗口（400ms）内忽略**；**静默清单（`panelCloseMuteMap`，含 esc）内面板一律不播** |
| `UI_CLICKED` | payload `{ variant, yRatio }` | 延迟 80ms 播放 `ui_click`（窗口内面板开/关则取消）；音量 0.75/0.45；rate = 变体率 × 位置变调（±25%） |
| `UI_HOVERED` | payload `{ yRatio }` | 立即播放 `ui_hover`（volume 0.35）；rate = 位置变调（±25%） |
| `TIME_WARP_CHANGED` | payload `{ rate, index, paused, wasPaused }` | `paused` → `warp_pause` 专属；`wasPaused` → `warp_resume` 专属（覆盖档位激活音）；否则 `warp` 激活音（档位变调，1x=原调） |
| `UI_WARP_HOVERED` | payload `{ rate }` | 播放 `warp` 悬停音（volume 0.35）；rate = 按档位映射 |

## 七、加载与自动播放解锁

- **加载**：`main.js` 将 `audioCore.init()` 与纹理加载并行启动，fetch + `decodeAudioData` 解码为 AudioBuffer
- **进度事件**：`AUDIO_PROGRESS`（单资源）/ `AUDIO_READY`（全部完成）/ `AUDIO_LOAD_ERROR`（失败）；加载界面音频进度条随事件更新，**纹理与音频都就绪才进入 splash**
- **失败不阻塞**：单个资源失败仅记录并提示，游戏照常进入
- **自动播放策略**：AudioContext 初始为 suspended，首次用户点击/按键后由 `audioCore` 统一 `resume()`
- **调试入口**：`window.__audioCore` / `window.__audioDirector`
